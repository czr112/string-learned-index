# N3 空间门：候选与基线逐字节相同（delta = 0）

日期：2026-10-22。候选：[块内再平衡](RESULTS_BM_N3_SUCCESS_20261021.md)；门禁前置见
[N3 门禁](RESULTS_BM_N3_GATES_20261022.md)。

## 做法

在**同一份内容**上分别构建基线与候选，三种状态各比一次 `memory_bytes()`：

1. 直接 bulk build（65,536 行）；
2. 相同 400 次插入之后（两条实现逐次核对插入结果一致）；
3. 从**同一最终 map**（65,936 行）各自重建——这一步排除增量路径的残留，只比结构。

## 结果

| 语料 | 构建基线/候选 | 400 插入后 基线/候选 | 同最终 map 重建 基线/候选 | delta |
|---|---|---|---:|---:|
| english_words | 1,944,569 / 1,944,569 | 1,960,745 / 1,960,745 | 1,961,232 / 1,961,232 | **0（0.0%）** |
| memetracker_urls | 6,176,841 / 6,176,841 | 6,120,515 / 6,120,515 | 6,222,028 / 6,222,028 | **0（0.0%）** |
| memetracker_phrases | 7,039,184 / 7,039,184 | 7,061,480 / 7,061,480 | 7,089,920 / 7,089,920 | **0（0.0%）** |

三语料、三状态，**九组比较全部 delta = 0**。块分裂引入的新块没有增加自计常驻——
`blocks_`/`stable_fences_` 的容量预留吸收了分裂，且分裂不移动 arena 字节。

## N3 门禁汇总

| 门 | 结果 |
|---|---|
| 四语料语义（含 400 insert / 150 update / 150 erase / 两次 verify / 终态 scan） | ✅ 263,469 项/格、失配 0 |
| ASan/UBSan/LSan（words） | ✅ 零失配、rc=0 |
| 失败注入与 `verify()` 不变量 | ✅ 逐次 verify 通过（1,200 次插入探针 + 门内两次） |
| **空间** | ✅ **delta = 0（九组比较）** |
| 四格三臂配对计时 | ⬜ **仍缺**（现有 56%–63% 是单进程对 R2 基线） |

## 判定

候选项在语义、sanitizer、不变量与空间四项上全部通过，且空间完全无代价。
只剩**配对计时**这一项：把它包成第四个臂（`bm_split`）与 `bm`/`art`/`ctx16`
在同轨迹、同进程内做 Williams 轮转与 AA 带比较，才能把 56%–63% 升级为正式结论。

在此之前候选不进入 N4、不改默认。
