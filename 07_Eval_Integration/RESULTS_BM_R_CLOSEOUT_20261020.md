# R 系列收口：BM 主线最终配置、成本结构与停止结论（2026-10-20）

本文件是 R0–R3 的收口，替代 R 系列各轮的分散小结；旧证据不删除，逐轮文档仍为原始记录入口。

## 1. 最终配置

| 配置 | 状态 | 依据 | 能力与边界 |
|---|---|---|---|
| **Context16** | **生产默认，不变** | 既有基线 | 完整动态接口、并发语义、长期评测 |
| **BM 页（只读实验场景）** | 保留，需显式选择 | 空间 0.427–0.731 ART、构建峰值 0.437–0.756（比旧全量复制低 53%–57%） | `bulk_load/find/scan`；`find` 1.03–1.86×ART；单线程；`range_sum` 不支持 |

## 2. 统一实验入口（R0）

`make_bm_experiment_index`：有界按页构建、默认 `find_base`、枚举 lookup、真实 `model_commit`/`core`/`adapter` 哈希。

- 公共 contract **100/100**；
- 三类真实语料各 263,121 项零失配（全行、全查询、缺席、边界字节、跨销毁 owning scan、200 insert + 100 update + 100 erase）；
- words 格 ASan/UBSan/LSan 一致；
- 差分门（vs `bm_bounded_page::Index`）每格 196,713 项零失配；
- `find` 零分配（计数 0）；
- 包装开销 adapter/core = 1.053/1.061/1.074，均在各自 AA 带（1.102/1.105/1.079）内。

## 3. 增长插入的成本结构（R1–R3）

| 观测 | 数值 | 来源 |
|---|---|---|
| 增长插入 vs ART/Context16 | 14.4–32.7µs vs 1.25–2.69µs（6–13 倍） | R1 |
| 页构建占写入 | 42%–47% | R2 |
| 根准备占写入 | 3%–8% | R2 |
| 旧页回收占写入 | 0.14%–0.33% | R2 |
| **两份临时行复制占写入** | **9.0%–12.8%** | R3 |
| 触发原因 | 页满分裂（52,428 行 26→51 页，每次重写 1,135–1,291 行） | R2 |

结论：
1. **差距不在查询**（BM 与 ART 持平），不在根（3%–8%），也不在回收（<0.5%）；
2. **也不在复制**：把两份临时行全部消除也只有 9%–13%，达不到 15% 门；
3. 于是页构建的余额（约 30 个百分点）落在**块切分、tag/CRC、arena 预留、fence/digest 计算**上，
   这属于页编码本身，需要新的机制而不是"少拷一次"。

## 4. 停止结论

按计划的停止条件（成本证据不支持改动 / 两次合理尝试仍无净收益），**增长插入优化支线停止**：
`split_from` 不实施，`FlatRoot` 与现有页编码保持不变，已验证的空间与构造成果全部保留。

若后续重启该支线，必须先登记以下之一并单独测量：

1. **减少重建次数**（更早分裂或按块余量分裂，降低单次插入触发重建的概率）；
2. **只重建受影响的一半**（另一半复用原页 arena 区间，单次成本减半）；
3. **复用模型拟合**（前缀与块边界未变时沿用上一版拟合）。

## 5. 仍未完成（需另立登记）

- 多进程配对与吞吐排名（R1/R2 均为单进程）；
- 真键替换（`update:erase:insert = 2:1:1`）与删除、扫描负载；
- 正确热点（登记规则要求 80% 热点写，实测上一轮只有 8.3%–10.1%，已作废）；
- 规模边界（>65k 唯一键）、百万规模；
- 短语 ≤0.70 空间目标（0.731）；HOT 适配器泄漏。
