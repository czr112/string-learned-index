# S1：修正均匀抽样、命中率与热点统计（24 条轨迹重新审计）

日期：2026-10-25。按[四步计划](CORRECTION_BM_TOTAL_20261024.md) 第 3 项的前半（负载修正）执行。

## 修掉的三处（复核指出）

| 原缺陷 | 修正 |
|---|---|
| "均匀增长"从排序后保留池**前段**取键（rank 3–4,974） | held-out 池**先洗牌**再按序取，插入键覆盖全 rank 范围 |
| 冷/热两组**命中率不同**（72.6% vs 86.4%） | **find 目标只按 live 集合均匀抽**，热点只影响**写**；两组命中率由构造相同 |
| 热点比例用**生成期估计** | 改为**回放最终轨迹**统计真实写入比例，并断言不低於登记值减去容差 |

另外：为保证热点配额可达，按登记规则**成对调整保留池**——
热点增长保留 1/2、热点替换保留 3/4（均在 manifest 的 `keep_fraction` 记录）。

**关键改进**：均匀与热点的**命中率差 ≤1%**（0.889–0.901），冷热对比不再混入命中率差异。
**热点**：增长格 0.800（恰好登记值），替换格 0.850（高于登记值，因插入也落在热区）；
审计只在**低于** 0.77 时失败——高于登记不是缺陷。
