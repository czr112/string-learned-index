# U3 实施规格：页分裂不重编码（先测"拟合 vs 拷贝"再动手）

日期：2026-10-29。依据 [U1b](RESULTS_BM_U1B_20261029.md)：整页重建占插入时间 **75.5%–95.6%**，
单价 140–334 µs、每次重写约 1,600 行。本文是 U3 的可执行规格，**尚未实现**。

## 第 0 步（必须先做）：把重建拆成"拟合 / 拷贝 / 目录"

当前 `Page` 构造函数在重建时做四件事，但**没有分开计时**：

| 阶段 | 内容 | 未知量 |
|---|---|---|
| A 前缀与块规划 | 扫一遍行算 region 前缀、块数、arena 大小 | 小 |
| B arena 写入 | 把每行后缀 `memcpy` 进 `arena_` | **可能占大头（1,600 行 × ~8 字节 ≈ 13 KB）** |
| C 模型拟合 | `blocklearn::BlockModel` 在块边界上训练 | **也可能是大头** |
| D 块/fence/digest | 切块、算 tag/CRC、填 `stable_fences_`/`digests_` | 中 |

**只有在 B 与 C 的占比明确后，才能判断"不重编码"能省多少**：

- 若 **C（拟合）占大头** → 省掉 B 也没用，应改"复用拟合"（同前缀的页共享模型）；
- 若 **B（arena 拷贝）占大头** → `split_half` 能直接省掉大部分。

**这一步只需给 `Page` 构造函数加四个 `steady_clock` 分段并累加**，改动 10 行以内，
不触碰语义，用现有四格轨迹即可测出。

## 第 1 步：`Page::split_half`（仅当 B 占大头时实施）

```cpp
// 从 src 复制 [blk_lo, blk_hi) 的块到新页，只拷贝这些块用到的 arena 字节。
static std::unique_ptr<Page> split_half(const Page& src,
                                        std::uint32_t blk_lo, std::uint32_t blk_hi,
                                        std::uint32_t new_region_prefix_len);
```

要点：

1. **只搬被选中的块**：`entries/tags` 逐块 `memcpy`（≤140 块 × 300 B ≈ 42 KB，仍需实测）；
2. **arena 压实**：把选中块的后缀字节按原顺序拷进新 arena，并**重写每个 entry 的 offset**
   （这是与"整页重编码"的区别：不再重新求公共前缀、不再重算每行后缀切片）；
3. **fence 重算**：新页的 `stable_fences_` 由各块首 entry 的 offset/length 直接构造；
4. **region 前缀**：若两半共享前缀则直接复用；若跨界导致前缀变短，**必须回落到整页重建**（受控降级）。

## 第 2 步：接入 `Index::rebuild`

`rebuild()` 在 `rows.size()>2048` 时走分裂；此处改为：

1. 以**源页**（`it->second.core`）为基准，按 key 位置算出切分点对应的块边界；
2. 两个半页各调用 `split_half`，插入新键所在的一半再走正常 `try_insert`；
3. 旧页在两半都构造成功后才释放（保持强异常保证）。

## 门（沿用项目既有标准）

| 门 | 判据 |
|---|---|
| 语义 | 三语料全行/全查询/缺席/边界/跨销毁 scan/增删改，零失配 |
| 不变量 | 每次插入后 `verify()` 通过；块序、槽范围、tag、fence 数一致 |
| 异常 | 三类分配失败注入后旧键完整、计数守恒、可继续 |
| 差分 | 与基线逐字段一致（构建期）；分裂路径逐次答案一致 |
| 收益 | 整页重建单价下降 **≥25%**（对应总写耗时 −19%–24%），且混合吞吐 +10% |
| 空间 | 常驻请求字节 ≤1.05× 基线 |
| 回退 | 查询不回退（相对原 BM ≤5%） |

## 停止线

- 第 0 步若显示 **C（拟合）占重建时间一半以上**，则 `split_half` 收益上限不足 15% →
  **不实施**，改为登记"复用拟合"方向，或直接结束容量支线；
- 两次实现机会用尽仍达不到 −25%，停止并记录。
