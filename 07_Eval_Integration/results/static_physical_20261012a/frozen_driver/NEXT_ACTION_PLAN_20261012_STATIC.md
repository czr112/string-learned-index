# 静态点查主线：预测与物理块对齐

日期：2026-10-12。基点：main@5f92496。用户已授权制定详细计划并开始执行。
本计划接替 M5 的执行优先级；M5 的 W/S 更新及扫描采用后移，既有结果及关闭决定保持原样。

## 1. 目标与边界

主目标是降低完整静态点查耗时、缩小与固定版本 libart 的差距。第一目标为 tranco；mixed/skew 为风险及机制对照。
不开展 LITS 定向优化，不改队友 BlockLinearRank 算法或参数，不重新打开 Q、PFX2、GD、M2 面板等负结果。
生产 Index 默认及源码本轮保持不变。首轮产物是拥有输入的独立只读原型，不冒充可更新索引。
ART 完整分配空间仍未提供，因此本轮不宣称空间优于 ART。

既有诊断：Context16 静态命中平均进入 mixed/skew/tranco 11.31/16.86/2.68 个块；
等深目录将其降到一个，却付出约八步依赖搜索，tranco 完整点查回归。
这要求同时改变落点预测和物理组织，不能仅以“访问一个块”判定成功。

## 2. 首轮唯一原型

暂称 StaticPhysicalBlocks，放在评测 diagnostics 下；不是新的生产后端开关。

1. 每 2048 个有序键一个区域，与当前区域划分一致。每区域只存公共前缀一次，后缀进入自有连续 arena。
2. 每个物理块最多 16 个有序活条目，含 16 个 CRC 标签及紧凑 offset/length/value 描述符。
   不为模型空组分配块，不保留写入容量；长键的后缀在 arena 中，不强求整个叶块只有一个缓存行。
3. 训练目标是实际物理块的 fence 序号，而非先预测逻辑组再遍历该组。
4. 使用独立的 7 个 9-bit 符号坐标（EOS=0，byte+1），保序但允许碰撞。
   坐标碰撞不得当作键相等，也不得跳过碰撞键所在的物理块。
5. 采用单调分段线性预测；按实际 fence 数据贪心扩展段，冻结正常证书宽度上限为 3 个块。
   证书对坐标等值族及相邻坐标之间的整数区间端点都计算保守界，覆盖未命中键。
   单个坐标碰撞族本身超过上限时，保留真实宽窗口回退，并单列其查询比例和最大窗口；不伪造有界性。
6. 查询执行区域摘要导航、公共前缀检查、坐标/段搜索、窗口内标签筛选及完整键比较。
   不借输入 fence，不预存查询答案或区域号，不免除剩余后缀 CRC 和键比较。

“多数查询验证 1–2 块”为研究目标，不是正确性前提。当前实现的第一证书上限选 3 块；
本轮不根据结果搜索窗口宽度、块槽数、坐标宽度或目标语料。

## 3. 对照臂与归因

| 臂 | 用途 |
|---|---|
| release | 当前 Context16，C/W/S 关闭，冻结发布开关 |
| C | 当前 Context16，只有 C 开启 |
| C_AA | 与 C 共用同一个实例、同一种查询调用；真实同配置 A/A |
| packed_directory | 原型布局，通过完整后缀 fence 二分找一个块 |
| packed_predictor | 与 packed_directory 共用同一布局及实例，只有定位方法不同 |
| ART | 既有统一接口 libart 适配器，厂商源码固定 |
| HOT | 既有统一接口 HOT 适配器，含已有查询复制成本 |

所有计时通过同一 v1::Index::find 虚接口及同一循环。packed 两臂共用同一个自有结构，
空间只计算一次；C_AA 不额外建索引。布局收益看 packed_directory/C；
预测增量看 packed_predictor/packed_directory；对外差距看各臂/ART、/HOT。
不将不同实验的比值相乘推算最终收益。

## 4. 执行阶段与交付

### S0：配置及身份冻结

- 核对工作树、实际 index.hpp/switches.hpp/模型/适配器/厂商源码、编译器和产物哈希。
- 新结果输出独立 identity，不回写旧报告。若旧 adapter descriptor 声明滞后，明确记录并以重算身份为准。
- 复用 matrix2 原始 rows/queries 做机制及历史队列对照，另生成冻结种子 2026101201 的新均匀 90% 命中流。
  新缺席键按独立有序参考核实不存在。输入记录、查询哈希及 seed 写入新产物。
- 编译统一 -O3 -std=c++17 -march=x86-64-v3，无计数/计时插桩、无 native。

### S1：原型、正确性与结构入口（本次立即执行）

- 验证全量语料键、历史和新查询；每个预测窗口必须包含独立完整 fence 二分的候选块。
- 覆盖空集、单键、NUL、高位字节、前缀关系、4096 长键、超过 7 字节的碰撞族、区域边界及首尾缺席。
- 穷举 65536 个两字节查询，另检查证书整数区间端点及其邻点；不得只在训练键上验窗口。
- 释放建造输入后再次验证命中和值，确认无借用。
- ASan/UBSan 独立构建；任何误路由/答案失配/诊断都阻止计时。
- 输出窗口分布、实际块进入分布、碰撞回退占比、段数、空间分解及构建时间。

### S2：有界完整 A/B（S1 通过即执行）

- 每语料 5 个独立进程 × 7 次重复；7 臂位置轮转，进程之间偏移起始顺序，绑同一个核。
- 每臂每次重复 20 遍完整查询队列。预热在计时外；完整 find、CRC、模型搜索、精确验证都在计时内。
- 同重复内配对，先求每进程比值中位数，再求 5 进程中位数。吞吐由同一累计时间计算。
  本轮不另跑逐操作计时的 P50/P99；窗口尾部计数不冒充延迟分位数。
- 先 tranco，再 mixed/skew；历史队列与新均匀流分别标注。所有臂每次 checksum 一致。
- 对称 A/A 带 F=max(max(r,1/r))，r 为五进程 C_AA/C 中位比值；这只是本轮观测带，不是置信区间。

首轮推进规则（不改判据挽救）：

1. 正确性全部通过，原型自有常驻记账不超过 C 的自有记账；分配器内部开销与峰值另列未知。
2. tranco 历史及新均匀流 packed_predictor/C ≤0.85，至少 4/5 更快且 1/比值 > F。
3. packed_predictor/packed_directory ≤0.95，同向至少 4/5 且超过 A/A 带，才证明模型预测有独立净收益。
4. mixed/skew 若回归 >5%、至少 4/5 同向且超过 A/A 带，标记场景限制，禁止通用默认。
5. packed_predictor/ART ≤1.20 是下一里程碑目标，不是本轮已有事实或强行通过要求。

若仅布局有收益、模型增量不成立：保留拆分结论，关闭本轮预测机制，不重调参数。
若第一目标不成立：完成必要风险计数/归因后收口，不启动动态集成。

### S3：条件采用及动态恢复（后续阶段）

仅 S2 通过才开：先交付显式只读类型，提供 owning scan，声明更新不支持；不能静默丢更新。
若要恢复现有 Index 的更新能力，另立版本失效、重建或写增量方案，计入两份状态的常驻及峰值、
首读重建成本、删除/重插和扫描代价。不得在静态收益上直接宣称完整动态替代品。
