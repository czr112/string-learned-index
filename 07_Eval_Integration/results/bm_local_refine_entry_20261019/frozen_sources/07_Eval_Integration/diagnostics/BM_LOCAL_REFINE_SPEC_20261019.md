# 阶段3：一层簇内 BM 前缀细分，工作入口登记

2026-10-19，起点 `f581eec`。承接 `LONG_TERM_BM_PLAN_20261018.md` 阶段3与
`RESULTS_BM_ENCODING_AUDIT_20261019.md`；登记在首次运行之前。本轮只计数，不计时。

## 唯一候选及对照

复制冻结 `bm_page_core.hpp` 生成独立 `bm_local_refine_page.hpp`；父 BM、物理槽、CRC、完整键验证不变。
构建时按父 BM 实际 prefix_size 后的7×9位坐标找连续 fence 簇。仅选择：

- 至少4个 fence，簇公共前缀比父模型前缀+7符号再多至少2字节；
- 一页中符合上述条件的 fence 占比至少10%。条件只看构建键，不看语料名或查询。

对每簇复用上游 `BlockModel::fit(views,1,7,8,1)`，一层、原参数，不换自研预测器。
模型前缀借用不可移动 Page 的稳定 arena；不复制前缀字符串、不常驻临时 view 数组。
按确切簇数量 reserve，记录 Family 对象及每个原 BM segment vector 的 capacity。

查找先用紧凑坐标找簇；未覆盖走原父 BM 路径。被覆盖的键，其精确字节前驱只能在
`[first-1,last]`（页首钳到0）；局部模型前缀不符或窗口边界检查失败时在此父区间完整二分。
局部模型训练半径始终只是提案；完整字节 guard 成立后才缩小搜索。最终仍用同一完整键验证。

同一候选对象另测 `family-directory`：同样找簇，但跳过局部 BM、直接二分父区间。
用于区分簇路由与局部 BM 拟合各自作用，不将目录收益记为模型精度收益。
保留冻结 BM-window、BM-base、完整目录及候选原路径控制；不混入短目录/cost/adaptive。

## 输入与正确性

沿用固定三真实样本和 tranco/64k（各65,536行与全库无放回查询）；每十条替换为
已证缺席的后缀键，约90%命中。主格 URLs，words/tranco 阴性对照，短语低收益对照。
全部键、全部查询、所有 fence 的前缀/后继/NUL 邻居与逐页全 scan 对 std::map 检查；
额外覆盖空页、空键、NUL、高位字节、4KB、长公共前缀、簇前后及0/MAX值。
四格全部跑普通和 ASan/UBSan/LSan，答案、布局身份、计数一致；失配即停止。
无插入/删除/更新或动态生命周期采用结论；该候选为只读。

## 工作与容量账本、入口判据

主格完整 fence 比较（边界+目录+局部 guard，分母为全部查询）相对 BM-window 至少少25%；
四格实际标签块访问和完整键验证不得增加；新增常驻容量/冻结页常驻容量各格≤5%。
完整披露额外坐标编码、family 紧凑比较、局部前缀比较字节、父/子模型调用和绕过比例。
逻辑比较字节不冒充物理读字节，工作计数不冒充纳秒。逐查询无插桩路径 C++ new 次数必须为0。
入口通过才另登记含根/统一接口/ART/F5/BM-base/family-directory 的完整计时，
仍须至少10%完整查询收益、4/5同向超AA且风险格无清晰>5%回归；本轮不预支资格。
任一工作或空间门失败就关闭本形态，不调阈值/段数/编码宽度或追加重复挽救。

运行前归档源码与输入哈希；运行后逐项复核原始整数、sanitizer、容量与判定。
