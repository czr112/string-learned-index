# F3 页内写余量：实现与计时前登记

接续 F2 必要读预算失败；F1/F2 源码和结果冻结。本轮唯一候选为固定分隔符覆盖的有序页内写槽，
不重开有序增量，不改哈希、编码宽度、16 槽块几何或 2048 活键页上限，不改生产默认。

## 覆盖构造

- 每块仍为 16 槽，初装 15 条；构建时另存首键的 arena 偏移/长度作为不可变 fence。
  fence 字节即使对应记录被删除也保留至页重建。除首块下端夹取外，块 i 始终只存 [fence_i,fence_i+1) 的完整键。
- 数值模型、D1 碰撞簇与证书仅依赖不变 fence。插入用完整 fence 前驱选块，成功插入仍满足相同范围；
  update 仅改值、erase 仅移除槽位，因此不使这些证书失效。查找继续同一模型范围、CRC/标签与完整键验证，无额外增量搜索。
- 每页 prefix 不变；不满足 prefix、目标块满、arena 余量不足、空页或超过 2048 活键，准备新页后发布。
  arena 为页内追加，初始字节额外预留 ceil(bytes/32)，不几何扩容；32-bit 限制按页检查。
- 页界用自持有完整键，首界空串，顶层沿用 F1 的 std::map，不叠新路由优化。满页按中点分裂。
  删除不立刻回收 fence 字节；compact 时低于512活键且与一个邻页合计≤2048可合并。
  任何分配/重建失败保留已发布内容。无重建的 update/erase/槽内 insert 不分配。

## 进入计时的门

1. 独立 std::map 语义：空/NUL/80/ff/长前缀/长键、删除首 fence 记录再插入、更早首键、区间内缺席、
   块清空、块满重建、前缀扩展、连续分裂/全删/相邻合并、跨页 owning scan、部分新页构建失败。
   普通与 ASan/UBSan 均通过，逐查询证书覆盖完整 fence 前驱，冻结 D1 模型函数保持来源可检查。
2. 三份真实语料做更新/插入/删除，并核查每次原地成功写入的 fence 身份不变；只重建目标页或至多一个邻页。
3. 无增量搜索由结构和完整查询工作路径证明，不将步骤计数换算为耗时。
   初建 F3 自报常驻/同数据 D1 自报常驻≤1.10（均非完整分配器口径），否则关闭本版布局，不调填充率挽救。

## 有界读预算

前三门过后，三份 E2 冻结行集各测 clean、1024次均匀既有键update后的dirty；约90%命中，查询顺序/缺席构造复用F2。
六臂 live/live_AA、同页路由紧凑16条构建 control/control_AA、D1/D1_AA；所有臂使用相同虚接口完整 find。
5进程×6次 Williams六行，同重复同置换。更新不改键集，control与D1从当前map构建，禁止跨轮比值相乘。
分别报 live/control（写余量净代价）与 live/D1（最终必要读预算），双比值各用对应双AA最大对称倍率带。
任一必测格 live/D1>1.15、≥4/5更慢且超过本格AA带，按F-10关闭本版进入全动态矩阵；未分辨不算通过。
不追加重复、不调阈值、不把控制臂相对旧轮快慢当作新候选收益。完整95/5、80/20与外部动态矩阵须入口通过再做。
