# BM物理叶页接入与首个窗口纠正优化：预登记

用户指定后续基于BM优化。本轮直接编译链接本地固定上游60837a88的block_model.cpp，算法/编码不改。
固定fit参数block_size=1、bytes=7、segment_budget=8、max_error=1；训练样本是实际物理块fence，y即块号。
不复用旧BlockLinearRank的rank→逻辑组映射，不搜索参数。D1/F5只作冻结控制，生产默认不变。

## 接入与优化差分

叶页仍使用F4/F5的有序16槽、初装15、固定fence、arena余量、CRC与完整键核对；根/dirty事务沿用F5。
BM的prefix_借用页内不可变fence所在arena。该arena仅在已reserve容量内插入，fence不擦除/搬移，
页对象禁止复制/移动，整页替换先准备新页/模型/根再发布；不依赖原输入行或临时训练views的寿命。
新页不训练D1分段模型或簇内预测器，不允许静默回退到自研模型。

BM原window只当proposal。统一将左边界外扩一块，保留缺席前驱；用完整fence检查左右覆盖边界。
raw控制：覆盖成立就扫描候选块；不覆盖时全页目录纠正。
优化臂：覆盖成立就在候选范围二分至精确前驱，仅核对一个块；不覆盖时只在已证明的左/右补集纠正。
两臂共用同一BM页、模型和物理数据，差分仅是窗口之后的纠正/验证组织。
目录控制不调用BM；自研F5保留独立冻结实现。训练certified不能冒充任意缺席键的覆盖证明。

## 正确性及实际使用证明

复用F5合成/三语料所有动态、dirty、分裂、合并、失败根准备、全删和owning scan回归，
独立std::map与冻结F5对照。每个定位同时核对raw/优化/完整字节目录；新增模型fence及其前缀/后缀间隙探针。
普通O2及ASan/UBSan必须全通过且语义输出一致。
记录BM window调用、proposal宽度、边界比较、补集纠正、目录步数、实际入块、模型段数及训练certified页数。
三语料逐键及缺席族证明真实BM调用>0，且BM调用+页前缀拒绝=请求数；核查新叶页无D1拟合调用。
原模型三源文件哈希前后不变，完整来源、失败尝试、命令、输入、二进制与源码归档保留。

## 性能入口

语义通过后，以同页raw/优化BM完整find先验证首个机制，完整字节目录和冻结F5作控制。
使用E2三语料及F5的clean/1024既有update状态和相同查询。计时次数、顺序、收益/风险门在测量前另登记。
收益目标：优化/raw在mixed及skew两个状态均至少减少10%耗时、>=4/5进程同向且超双方AA带；
tranco两态不能有>5%、>=4/5且超AA带的清晰回归。未分辨不能声称收益。
首轮不以失败为理由改BM参数或追加重复。与ART/HOT的排名必须用原BM新版本直接测，不能相乘推导。
