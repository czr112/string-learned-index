# F1 局部页更新：实现前登记

起点 `49183a4`，在既有未提交 C2 诊断收口后执行长期路线 F。只交付独立实验类型和正确性/维护门，
不改变生产默认；F2 的同能力性能与空间采用门仍须另行测量。

- 每页最多 2048 个活键，页内复用冻结 D1 的 16 槽物理块、7 符号编码、模型与完整键验证。
  每页自持有 arena；不保留一份全库行副本。
- 页界使用自持有完整字节分隔符；首界为空串（字节序最小值），其后为半开范围。
  顶层用有序树更新路由，查询内使用当前页的定位契约，不支持跨发布保存 Location。
- 页内有序增量最多保留 127 条；达到 128 条，或容量/键堆字节达到该页基底自报常驻的 10%，立即合并。
  单个长键超过预算、活键清空时也同步合并；阈值在计时前固定，不搜索。
- 活键超过 2048 时按中点分裂。合并时若活键少于 512 且与一个相邻页合计不超过 2048，可合并这两个页。
  其他稀疏页暂保留；不做全库重排。
- insert 重复保旧；update 缺席不插入；erase 缺席无变化；0/MAX 是合法值。
  scan 合并基底与增量，消除墓碑和旧值，满足 lower_bound/limit，返回自持有键。
- 写入先准备页内增量；必要时构建替代页和路由节点，最后无分配发布。任何发布前失败保留原 map。
  注入失败只用于正确性门，覆盖普通重建和分裂中已建部分新页的情况。
- 单列重建页数、重建行/键值逻辑字节、增量复制、路由节点变化以及原页/新页/暂存行同时存在的自报峰值。
  std::map 节点开销和分配器元数据未知，不将这些数宣称为完整堆峰值。每次重建只涉及目标页和至多一个邻页。
- 独立 std::map 对照：空键/NUL/80/ff/长前缀/长键、边界新增、删最小键后重插、连续分裂/相邻合并、全删、
  失败回滚、跨页扫描、确定种子随机混合写。普通与 ASan/UBSan 均须零失配。

通过 F1 只代表语义和局部维护入口成立。后续 F2 才测 95/5、80/20、均匀/集中写、替换/增长，
对照同 map 的重建只读快照、动态 Context16 与能力匹配的 ART/HOT，验证查询开销 ≤15% 和维护/空间预算。
