# F4 同叶页路由/包装归因（计时前登记）

起点 F3：tranco 两态 live/D1=1.283/1.276，而同页紧凑控制同样有差距。
本轮只做有界2×2反事实：根导航 tree/flat × 页入口 wrapped/single，四臂共享同一实例、同一批F3叶页。
不改变页对象字段、15/16槽布局、arena、模型、CRC或完整键验证，不改原F3源码/失败记录/默认。

## 唯一两个差分

1. tree 为原 std::map::upper_bound。flat 用同一组自持有页界和页指针，公共前缀+固定8字节摘要数组二分，
   摘要相等仍完整键比较；首哨兵空串独立处理。只更改根导航，不新增段切点、不重开C1。
2. wrapped 为原F3 Page.find。single 仅将 Page 内 locate(key) 的区域号替为0：
   构造器已经限制 rows≤2048、region_keys=2048，所以只可能0或1个区域。
   空页判断、页前缀验证、模型/证书/纠正、CRC/标签和完整键比较全部执行；不向调用者借预知页号。
   根导航仍每次读取完整查询实际完成。四臂返回相同完整答案。

平铺目录仅在本轮冻结拓扑上使用；构建后只有值更新，拓扑变化须重新发布根目录。
本轮不把 O(页数) 的数组构建/搬移包装成已局部化动态更新，也不据此发布可更新索引。

## 门与范围

- 域门普通与ASan/UBSan：空/单页、多页、任意字节/NUL/EOS/80/ff、长前缀、页界及其邻居、
  同摘要不同完整键、首尾夹取；根选择相对独立完整字节 upper_bound、single 相对原Page的范围/答案完全相同。
  原F3对象作独立答案对照；所有新数据源/生成器身份归档，新增方法不能改变旧对象布局。
- 主格 tranco/64k clean 和1024次均匀既有键update后；风险格 mixed/skew clean。查询复用F3种子、约90%命中，
  每重复共享置换。先完整核对查询/scan与参考和sanitizer门，再计时。
- 四臂及各自同实例AA，共8臂；5进程×8次Williams完整行，同一虚接口真实完整find，固定O3/x86-64-v3/同CPU。
  比值逐重复配对，先每进程8次中位，再5进程中位；比较双方AA的最大对称倍率作观测带，非置信区间。
- 报 flat_wrapped/tree_wrapped（只改根）、tree_single/tree_wrapped（只去冗余页导航）、
  flat_single/flat_wrapped（固定新根再改页入口）、flat_single/tree_wrapped（组合），不由比值相乘推导。
  root或single一个独立差分在两个主格均≤0.90、≥4/5更快且超过AA带，且风险格无>5%清晰回归，才可进入对应单机制原型。
  若仅组合通过，记录交互，不能声称某一步已单独解释差距。
- 完整字节比较/摘要比较计数独立执行，不用于计时排名，不换算纳秒。计时臂不携带计数分支。
- 不加重复救结果。本轮没有D1/ART排名；通过归因也不等于通过最终15%读预算。

若有单机制通过，下一步先构建一个相应的动态集成，明确根目录拓扑发布成本，并修复compact全页重建，
再过同map D1必要读门；若均无证据，归因收口未知，不继续堆路由候选。
