# BM 按页构建单机制优化（运行前登记）

基于已独立复核的 bm_space_20261019b。四格 BM 常驻为 ART 的43%–73%，
但构建峰值为104%–160%，未形成组合入口。薄适配器先复制全部rows再逐页复制，是明确临时量。
本轮只消除这一次全量转换；不更换BM、Page、FlatRoot、页大小、布局、find或维护方法。

生成独立Index头：构造函数接受已有行类型，在每批最多2048行内转换为原Row，直接调用冻结Page。
其余Index方法逐字保留，旧源码/实验不改。生成独立adapter和ledger，当前默认不改。
同轮三臂为bm_bounded、原bm_base、固定项目ART，四个原65536键样本。
原生完整工厂的慢构建和保留输入结论已在前轮记录，不加入此单因素轮。

沿用 BM_SPACE_SPEC_20261019 的追踪器、输入/输出分账、3次独立容量、5次独立干净构建及全部组合门。
追踪器与前轮不改、不和ASan混用。当前空间目标仍≤0.70 ART；必要空间<1，
build有效requested峰值≤1.00 ART且干净构建中位数≤1.20 ART才算空间场景入口。
不以跨轮ART/时间倍率推断本轮结果，不用单项空间或旧查询结果代替组合判据。

先普通/ASan/UBSan/LSan公共接口与逐键、缺席、owning scan，新增差分布局门：
两种Index的页边界/版本、全部fences、模型段数/认证数、根容量、逻辑容量一致，verify均通过；
所有行与相同混合查询的find_base答案相同。实测owned requested常驻必须逐字节相同，查询零分配。
峰值目标为四格均低于原bm_base且≤ART；构建耗时只报五进程原数及中位数，不声称统计显著。

若组合入口成立，下一步先冻结新样本/较大唯一键规模确认，再决定有限动态入口。
若只解决峰值而构建时间仍不过，按真实失败格收窄，不调拟合、批量大小或补性能重复。
这一轮不重开查询机制、不测查询/scan吞吐，不宣称通用替代或采用资格。
