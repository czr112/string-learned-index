# C1融合段边界导航：入口定义

起点B阶段df32246；只审计冻结输入与同一训练/布局，不计时、不改生产默认，不做LITS优化。
唯一机制：由每个区域的模型段xmax构造完整字节序切点，放入一份紧凑摘要导航；一次搜索同时给出区域和段。
沿用8字节摘要，摘要相同完整比较。区域/编码/训练/16槽/CRC不变，scan继续使用原区域导航。
模型的闭区间证书保持原义；这里仅选择原段，不重拟合或缩窄证书。

短于7个符号的坐标，其最小后继字符串为原串+NUL；满7符号时对固定7字节做字典序进位并截去尾部。
最高坐标无后继；只有内部段边界需要切点。每个区域首fence也作为切点。首端夹取，尾段仍保留x>xmax末块判断。
前缀拒绝只决定点查缺席；本入口不改变scan。

主格tranco/64k的10k和100k、mixed/full/10k；风险tranco/full/10k及100k、mixed/full/100k、skew/full/10k及100k。
逐请求独立行前驱确认区域，模型数值段参考确认有效前缀下的段身份；计数副本与冻结B的结果和已记录工作逐请求一致。
账本含区域摘要搜索/完整比较、模型段搜索、目录纠正、CRC逻辑字节、实际进入块及精确比较。
逻辑比较字节不等于memcmp物理读取或CPU周期，不从计数构造纳秒。

进入功能原型须所有主格同时满足：
1. 所有检查零失配，切点严格有序，区域/段覆盖成立；
2. 至少80%请求原来执行模型二分，现在可以由一次导航直接选段；
3. 新的导航比较次数不超过原“区域+模型段”比较的1.10倍，完整字符串比较增加不超过每请求0.5次；
4. 包含对象及自持有切点的新常驻不超过B静态记账5%。

若入口失败，关闭C1，不做计时、不搜索摘要宽度/阈值或追加另一种结构来救C1。
若成立才实现查值原型，过二进制域/scan/sanitizer后按长期路线10%收益及风险门做一次A/B。
保持原S3的7.8%失败判定；不把入口工作减少当作完整查询收益。
