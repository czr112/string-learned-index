# 短目录（ShortDirectory）消融：登记

2026-10-18，起点`571adb1`工作树。[BM首轮](RESULTS_BM_LATEST_20261018.md)已判定窗口纠正不采用，
[predicted-first括号](RESULTS_BM_BRACKET_ENTRY_20261018.md)已按计数否决。
本轮执行计划中的**短目录**消融；cost/adaptive planner与payload探测仍各自另做，不并行启用。

## 1. 唯一差分

上游`blocklearn::ShortDirectory`（`short_directory.h`，e8e05411）把每页的物理块fence压成
63位（7符号）编码后做有序路由：不等码直接确定整键顺序，**码相等时才回读真实fence**；
括号校验不成立时返回`nullopt`，调用方保留原完整路由。本轮把它接到BM叶页：

- `current`：现有BM定位（窗口两端fence比较 + 窗口内二分，越界时半页二分）。
- `short`：先走`ShortDirectory::predecessor`；命中则直接进入该块，未命中回退到`current`。
- `directory`：完整字节目录控制（同页全部fence二分）。

三者进入**同一个**完整键校验；布局、模型、槽位、CRC、根导航不变。唯一新增常驻是每块8字节编码
（本例1,096字节/页，137块），**不在**页对象自报容量内，单独报告。

## 2. 通过/停止条件（预登记）

1. 正确性前置：每页全部键与全部查询，`short`/`current`的前驱块必须等于完整字节目录；
   计数的replica必须与上游实现逐条同判（命中返回同一块、未命中则等于回退结果）。任一失配即停止。
2. **结构门**：`short`的完整fence比较次数/查询 ≤ 0.30 × `current`；允许数值比较次数上升，
   因为63位比较与"随机访存的fence字节比较"不是同一种工作。五格都要过。
3. **计时门**（仅在上述通过后）：主格tranco/64k 100%命中的`short/current`中位≤0.90，
   且任一格不超过1.05、至少4/5进程同向、超过双方A/A带，才作为完整读门的候选。
4. 停止条件：结构门或计时门任一不过即关闭，不调编码宽度/段数/槽位挽救，不改上游。

## 3. 口径

计数为fence字节比较、数值（63位码）比较、回退步数与进入块数，逐请求均值。
计时是**页级定位**：查询到页的路由在计时外预先算好，六个臂（`current`/`current_AA`/`short`/
`short_AA`/`directory`/`directory_AA`）在同一页对象上配对，5进程×6次、每repeat换查询置换；
六臂校验和必须相等。根导航不在本轮计时内，因此**不是**完整点查耗时，也不做ART/HOT排名。

## 4. 不做

不改上游`ShortDirectory`/`BlockModel`、不搜索`bytes/segments/max_error`、不改15/16槽与CRC、
不把训练窗口当缺席证明、不扩动态矩阵、不据本轮改生产默认。
