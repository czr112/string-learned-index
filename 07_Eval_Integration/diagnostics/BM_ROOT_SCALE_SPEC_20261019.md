# 阶段5根成本：随页数增长的量化（登记）

2026-10-19，起点`0eb7d66`工作树。依据[最新长期计划](../docs/LONG_TERM_BM_PLAN_20261018.md)阶段5第4条：
“现根换页仍O(页数)复制。先测随页数增长的维护占比；只有根复制形成显著线性瓶颈时，
研究有序分层目录的路径复制或分块发布”。

## 1. 差分与口径

同一插入批次（1,000个合成增长键，均匀分布在源键上）分别施加在32/49/64/128页的输入上；
只改输入规模，模型、页、根、构造与插入路径不变。记录：

- `pages`/`pages_after`、`publications`（根发布次数）、`rebuilds`；
- `entries_copied`/`key_bytes_copied`（取维护计数器的增量）；
- `entries_per_publication`与`entries_per_publication / pages`（判定“整根复制”的线性证据）；
- 逐插入暂停p50/p95/p99/max，构造耗时与批次耗时。

## 2. 判据（登记）

- 正确性前置：1,000次插入全部插入成功、失配0。
- 判定“根复制随页数线性”：`entries_per_publication/ pages` 落在[1,2]内
  （发布发生在新页已加入之后，因此会略高于当次之前的页数）。
- `path_copy_justified`：任一规模下1,000次插入累计复制条目 > 4×2048（即根工作量已达页级重建量级），
  记为需要研究路径复制/分块发布。这只是**触发研究**的条件，不是采用结论。

## 3. 不做

不改根结构、不做24格、不测吞吐、不排名；也不把本批合成增长当作混合负载。

## 4. 结果摘要（执行后填写）

entries_per_publication/pages四档为1.52/1.50/1.51/1.50（整根复制）；1,000次插入累计复制条目1,552→3,528→6,176→24,640（32→128页），即随页数平方增长；skew键字节复制是tranco/64k的48倍。`path_copy_justified=true`（触发研究，不采用）。详见[执行结果](../RESULTS_BM_ROOT_SCALE_20261019.md)。
