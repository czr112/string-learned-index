# 阶段2入口：预测块 payload 优先探测（登记）

2026-10-19，起点`ed11b47`工作树。依据[最新长期计划](../docs/LONG_TERM_BM_PLAN_20261018.md)阶段2：
“先探测预测块中的实际键值，完整键匹配就返回，否则走安全纠错”。

## 1. 唯一差分

在同一BM叶页上新增一条定位路径（诊断副本 `bm_probe_page.hpp`，算法其余部分逐字不变）：

1. 一次 `bm_.locate()` 取 `predicted` 与窗口（不调用两次模型）。
2. 直接探测该块的16个标签：只对**长度相同**的候选做完整字节比较；相等即返回该值
   （提前返回由完整字节相等证明）。
3. 未命中则走**原有**窗口检查+方向纠错+完整键校验；该块在这次查询里已证明不含目标键，
   因此回退时跳过它的标签扫描（避免“已探测块重复校验”），但计次保留。

模型参数、页布局、槽位、CRC、根导航与生产默认均未改；不新增常驻。

## 2. 输入

真实三类键（english_words / memetracker_urls / memetracker_phrases，各65,536键）为主判据，
tranco/64k 为机制阳性对照；每十条查询替换为已证明缺席的后缀键（~90%命中）。

## 3. 判据（登记，仅工作量入口）

- 正确性前置：每页全部键与全部查询，`probe`、`current` 与完整字节目录三者答案必须相同；任一失配即停止。
- **入口门**（计划原话：主格减少至少25%的额外定位比较或标签批次，另一类工作无明显放大）：
  主格`english_words`的fence比较需减少≥25%，且四格的块访问（标签批次）不得增加。
- 未过入口门则**关闭该方向，不计时、不追加重复**；按计划的“连续两个候选入口失败即停止该方向”
  （前一个为预测前驱括号），预测块族到此为止，回到阶段1证据重选瓶颈。

## 4. 结果摘要（执行后填写）

主格fence比较仅降8.3%（6.162→5.651），块访问从1.00升到1.92/查询；命中率7.7%–9.0%。入口门两条均不过，**候选关闭且不计时**；预测块族累计两次失败，按计划停止该方向。详见[执行结果](../RESULTS_BM_PROBE_20261019.md)。
