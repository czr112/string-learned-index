# 阶段5根机制入口：分块 COW 发布 vs 整根复制（登记）

2026-10-19，起点`942e788`工作树。依据[最新长期计划](../docs/LONG_TERM_BM_PLAN_20261018.md)阶段5第4条：
根复制已确认是`O(页数)`整根拷贝，本轮登记**一个**根机制入口——16键分块 + 写时复制（COW）发布，只复制受影响块与块首索引。

## 1. 差分与口径

- 用真实BM页的真实页下界构造`ChunkedRoot`（每块16个下界键；块首索引另存），
  与现有`FlatRoot`（整根绑定数组 + digest二分）对照；
- **不修改**生产索引，也不在计时回路里访问页或模型：本轮只比**路由**与**发布工作量**；
- 发布工作量按“一次发布必须复制的条目/键字节”计算：`FlatRoot`整根；`ChunkedRoot`为块首索引 + 一个块（其余块共享）。

## 2. 判据（登记）

- 正确性前置：对全部页下界、全部行键与全部查询，分块路由与`FlatRoot::locate`必须选中同一页；失配即停。
- **入口门**：路由开销变化 |chunked/flat−1| ≤ 5%，且三格（32/64/128页）的发布条目降幅均≥25%。
  两者同时满足才允许进入集成（真实页指针、发布/回滚语义与完整读门）。
- 只报告观测，不据此改根、不改默认。

## 3. 不做

不改`FlatRoot`/`Index`、不测写吞吐、不做24格、不排名；分块大小只取16，不做参数搜索。

路由chunked/flat=1.027/1.022/1.005（≤5%）；发布条目降幅43.8%/68.8%/81.3%（≥25%），键字节降幅46.1%/71.4%/82.4%；三格131,104–524,352个键路由零失配，360行计时。**入口门通过，允许进入集成**（本轮未集成、未改根）。详见[执行结果](../RESULTS_BM_ROOT_CHUNK_20261019.md)。
