# F2 读开销入口（计时前登记）

F1 普通/sanitizer 四份门均通过后，先检查长期路线 F-10 的必要条件：相同当前 map 下，
动态点查相对重建只读快照的开销不超过 15%。本轮是进入完整同能力读写矩阵前的有界筛选。

- 三份 E2 冻结行集：tranco/64k、mixed、skew；各两种状态：初建无增量、1024 次均匀既有键 update 后。
  值修改成功才更新独立参考；不插入/删除，避免本轮同时改变路由几何。
- 每格查询数等于输入键数，复用 E2 全库置换键；每十条中一条追加固定后缀构成缺席，先对 std::map 核实，
  其余查询答案按更新后的 map 重算。每次重复另行置换，同重复四臂相同。
- 动态沿用通过 F1 的完整类型；对照为当前 map 的冻结 D1 只读快照。相同虚接口完整调用 find，
  不计写入或重建为查询；独立参考先检查全部查询、owning scan 和页内证书。
- 四臂 local/local_AA/snapshot/snapshot_AA，AA 为同实例同调用。5 个新进程 × 8 次重复，
  四臂 Williams 四行完整运行两遍，每进程旋转起点；绑同一 CPU。固定 O3、x86-64-v3。
- 同重复配对，先每进程取八次比值中位数，再取五进程中位数。A/A 带为两组 AA 配对的对称最大倍率。
  任一必测格 local/snapshot >1.15、至少 4/5 同向变慢、且超过该格 A/A 带，即阻止该桥接组织进入全面采用验证。
  结果未分辨不算通过，不追加重复；保留全部六格。
- 记录基底/增量/路由自报空间及更新导致的局部重建；不宣称完整分配峰值，不计时间外写入吞吐。
  如必要读预算失败，本轮不铺 95/5、80/20 与 Context16/ART/HOT 外部矩阵，也不修改门槛或堆叠缓存挽救。
  后续评估页内写余量或新的路由方案须另立结构候选；F1 的正确性与局部性成果仍保留。

本轮不改变生产默认，不从不同能力的只读对照发布动态吞吐或对 ART/HOT 排名结论。
