# B阶段接缝执行定义（计时前登记）

唯一差分：从S3只读核心提取显式半开物理块范围及公共键验证入口；精确目录和当前模型使用同一布局。
旧文件不改，生产默认不改。新对象多保存region_keys构建身份（本机8字节），完整计入对象空间。
复用原S3类型、CRC、坐标函数；训练器、arena、区域划分、16槽和scan算法保持一致。

正确性先行：原共用v1验收；四份S3冻结输入（tranco full/64k、mixed/skew full，100k请求）的全键/请求、
块边界与缺席邻居，独立逐字节有序参考复核区域/物理前驱；三策略逐请求全部已记录工作相等；
空/单键、EOS/NUL/80/ff、4096键长、同坐标碰撞、多种非整块region尺寸、非法范围、生命周期与owning scan。
scan含前缀拒绝及块间隙、跨区域、limit 0/最大、结果跨析构。四份O2和ASan/UBSan门均须通过，之后才计时。

有界无优化A/B：主格tranco/64k/100k，风险mixed/full/100k、skew/full/100k；不新增ART/HOT排名。
同一完整v1虚接口、相同unique_ptr所有权包装与状态检查，4个独立核心实例；new_model/A_A和new_directory/A_A分别同一实例。
标签顺序old_model、new_model、new_model_AA、old_directory、new_directory、new_directory_AA。
5进程×6 Williams行：基行0,1,5,2,4,3，按repeat+process模6平移，位置/有向前驱平衡。
每臂即时完整队列预热，随后2遍=200k操作；g++13.3.0 O3/C++17/x86-64-v3，无LTO/NDEBUG，固定可用CPU。
编译自行重建所需源，绑定编译器依赖、输入及二进制哈希；不复用前轮.o。工作量验收不在计时进程运行。

每进程6个同重复新/旧比值取中位，再取5进程中位；模型与目录各用自己的同实例A/A对称观测带F。
清晰回归：比值>1.05、≥4/5更慢且超对应F；清晰收益：<0.95、≥4/5更快且倒数超F。
未分辨不证明零成本，不重跑/追加重复挽救负结果。B不宣称新优化收益；回归则保留实验接缝并阻止性能采用，
独立C候选可在保留旧控制下研究；原S3的7.8%失败不因此撤销。非法装置才另名修正并保留原记录。
