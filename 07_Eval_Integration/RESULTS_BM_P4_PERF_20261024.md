# 优先级 4：A/A 校准后的性能与吞吐验收（8 进程块，审计后轨迹）

日期：2026-10-24。轨迹来自[审计后的 24 条](RESULTS_BM_P2_AUDITED_20261024.md)，空间见[优先级 3](RESULTS_BM_P3_SPACE_20261024.md)。

## 协议（本次预登记并执行）

- **8 个进程块**，四臂**完整平衡循环**（每臂在每个位置出现两次）；
- 每臂一次预热、两次计时（第二次作 **A/A**），逐臂逐指标校准噪声；
- 计时回路**不含**预言机；
- 除逐操作计时外，另报**整段混合吞吐**（`ops / seg_us`），这是逐操作汇总不能替代的。

## 三点结论（含一处推翻旧结论）

1. **增长收益稳定**：60.3%–64.2%，8 块区间下界也 ≥36.6%，**全部超出各自 A/A 带**
   （BM 自 A/A 1.05–1.29、候选 1.09–1.50）。
2. **替换在合规轨迹下也有收益**：45.5%–47.9%——**推翻**此前"替换无效"的判断。
   原因是旧轨迹的替换很少有真实新键插入（`~r/` 拼接且多为重复），修正后的
   "erase 真实键 + insert held-out 真实键"才会触发块满分裂，机制因此生效。
3. **整段混合吞吐同步改善**：1.16–2.25×。
4. **查询门有一格未过**：words 80/20 均匀替换的 find 比 **1.065**，略超 5% 门。
   其余格 0.849–1.047。因此"查询无回退"应记为**除该格外通过**，需要复查该格或补配对确认。

## 判据核对

| 判据 | 结果 |
|---|---|
| 增长格 ≥15% | ✅ 60.3%–64.2% |
| 超出 AA 噪声（按臂/指标分别校准） | ✅ 全部超过各自自 A/A |
| 整段混合吞吐 | ✅ 1.16–2.25×（新增指标） |
| 查询无清晰 >5% 回退 | 🟡 **一格 1.065 超门**，其余 0.849–1.047 |
| 空间 ≤1.05× | ✅ 0.999–1.003（真实账本，含临时空间） |

## 边界

- 8 格（words/urls × 增长/替换 × 均匀/热点，65k）；独立样本与 100k 属优先级 5。
- A/A 仍偏宽（候选最大 1.50），故"超出噪声"是按**每格每臂**判断，不用全局最大带。
- 单机单核（`taskset -c 0`），未跨机器复验。
