## 2. fault 补充（两轮，结果目录 `results/bm_fault_supplement_20261025/` 与 `results/bm_fault_literal_20261025/`）

**共同覆盖（两轮相同）**：bytes+三语料 × 7 路径 × 逐分配序号穷举 = **22,739 次真实注入 +
28 次成功对照**（每构建）；opt 与 sanitizer（ASan+UBSan+`detect_leaks=1`）两构建都跑。

- **第一轮（mixed）**：每注入点后 1,000 次**混合**操作（各 200 insert/update/erase/find/scan）+全量核对；
  两构建各 518,048,177 项检查、零失配、销毁零泄漏。sanitizer 零报告。
  → 关闭"sanitizer×注入×三语料"覆盖缺口。
- **第二轮（literal）**：每注入点后 5 次**混合**（保持 S0 剖面连续性）+ **1,000 次纯插入/删除**
  （500 对插入-擦除，键 `~writes/N`）+全量核对——满足旧计划 §2.3 的字面措辞
  "继续执行 1,000 次插入/删除"。两构建各 **22,739 次注入 + 28 次成功对照、
  271,808,717 项检查、零失配、销毁零泄漏**；sanitizer（ASan+UBSan+LSan）对三语料
  穷举注入零报告。逐语料（注入数/检查数，两构建相同）：bytes 2,203 / 21.2M；
  words 2,285 / 22.2M；urls 10,418 / 129.4M；phrases 7,833 / 99.1M。
  二进制身份与依赖闭包（`f2894730…`）见 report.json。

**边界**：`--suite fault` 只是覆盖补充，不构成完整 S0 验收（无 24 轨迹差分与空间门）；
不新增性能或空间结论。

## 3. 包装门（结果目录 `results/bm_wrapper_gate_20261025/`，16 进程版）

**首轮撤回**：5 进程版判定的 AA 条件无效（`median≤1.05 ⇒ min≤hi` 恒真），且复测显示
5 进程下 AA 噪声本身超过 ±5%（三语料均 `measurement_unresolved`）——首轮"pass/2.71%"作废。

**现行判定规则（预登记于 runner docstring，与 `run_bm_query_recheck.py` 统计同构）**：
单元=进程（16 个），每进程 8 个配对重复在 log 空间平均；每次计时至少 40ms 校准环
（分析用 ns/操作）；W=每进程 log(adapter/core)→几何均值+t 区间（df=15）；
AA=adapter_AA/adapter 与 core_AA/core 各自同法；**AA 质检=两个 AA 的 95% 区间都落在
[1/1.05, 1.05] 内**；verdict：区间上界 ≤1.05 为 pass，下界 >1.05 为 regression，
跨 1.05 为 undecided，AA 不过为 measurement_unresolved。

| 语料 | 几何均值 | 95% CI | AA 质检 | 判定 |
|---|---|---|---|---|
| words | 1.0073 | [0.9854, 1.0296] | ok | pass |
| urls | 1.0038 | [0.9809, 1.0273] | ok | pass |
| phrases | 0.9933 | [0.9698, 1.0172] | ok | pass |

**判定：三语料包装成本 95% 置信上界 ≤3.0%，≤5% 门通过。**功能性部分（答案/结构字节/
基数差分、find 零分配实测 0）全部通过。边界：65,536 键三语料；100k 与替换语义未测，不外推。
