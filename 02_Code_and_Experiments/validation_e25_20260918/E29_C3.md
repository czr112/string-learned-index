# E29: does the relaxed compaction trigger pay for itself?

Source: `results/main/long_c3_{same,grow}.jsonl`, 1080 records.

**C2 is the frozen version**; **C3 = C2 + one switch** (`compact_repack_budget`).
Both run in the same process, so every ratio is paired inside a repetition.

C3 relaxes the trigger from "some single sub-block has a free slot AND enough
suffix bytes" to "a full repack of the group would fit". The E28 measurement
showed the old condition is exactly the one that is usually false while the
group still holds reclaimable garbage.

Correctness is checked by `check_c3`: content and key order identical to the
frozen version and to the reference at every checkpoint, on all three datasets.
