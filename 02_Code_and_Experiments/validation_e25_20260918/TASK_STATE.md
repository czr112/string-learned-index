## 当前决策

**默认版本 = 启用 V1 与 V2**（`write_fast_locate` + `reuse_locate_ctx`）。
依据：`V1÷V0` 在 9 个 (数据, 负载) 格中 9 格同向；`V2÷V0` 同样 **9/9 同向且全部 5/5**；`V2÷V1` 在任何一格都没有一致劣化。**重复前缀上 V2 的增量落在噪声内**，按格如实标注。
**不是仅凭调用次数减少作出的选择**——依据是同轮完整操作耗时。

**尚未落到代码默认值。** `Config` 当前默认两开关仍为 `false`（= V0），因为本轮所有测量都在显式设 flags 的前提下完成；**在阶段五翻转默认值并做一次确认运行**，避免改动使已测量的二进制失效。

**给 E26 的一条线索**：重复前缀上 `insert` 每操作哈希 2646 字节而单键仅约 156 字节——多出的部分来自 **`compact()` 对每条被重放记录调用一次 `Fingerprint::of`**。V2 每操作只省 88 字节（占 3%），这就是 V2 在重复前缀上量不出收益的原因。
