**分支 C 这一轮同时推翻了自己写下的三条说法**（详见 `RESULTS_BRANCHC_ENTRY.md` §3）：

1. **E24 的推断不成立**：`22%–30% ⇒ 记录已减少但容器仍保留`——**同一口径的 21.28% 出现在一个零回落的检查点上**；
2. **设计里 A/B 的「可回收性」标注是算术错误**：收缩从分配的**顶部**拿容量，缩到活跃数收 `A+B`、缩到峰值收 `A`，**两项都收得到**，A/B 分的是**耐久性**；
3. **W1「Term B 按构造恒为 0」是「总量不变 ⇒ 每个元素都不变」**——**本项目第三次同型错误**。
