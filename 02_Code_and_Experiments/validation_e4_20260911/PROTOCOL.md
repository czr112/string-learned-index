# E4：跨区域测量、独立验证选择和原生基线

协议在正式计时前固定；结果不得用于改候选集合或选最终策略。

- 继承 E3 的存储、模型、路由与预算选择器；新增可复用跨区域测量和验证选择流程。区域 2048 键，模型×块宽共 9 候选，加前缀压缩有序叶。
- 固定三组主实验：skew 131072、mixed 262144、Tranco XN6XN 1000000。CPU 0 串行，GCC -O3 -march=native。共享主机，批次平均耗时不是单请求尾延迟。
- 数据按排序后的 rank % 8 分割查询身份：0/1 调参，2/3 验证，4/5/6/7 测试。索引正常装载全部键。这是本轮内隔离，不声称历史各轮从未查询这些键。
- 50% 命中、50% 未命中；后者追加 ~missing~，生成阶段核对不存在。所有查询拥有独立字符串内存。原生基线共同使用不含 NUL 的 ASCII 键；该协议不检验任意二进制键。
- 每区域调参 128 次查询；局部代理测量对区域内查询连续执行，3 轮×4 遍。跨区域代理测量随机交错查询，完整外层路由计入时间，3 轮，逐查询打时钟后按实际路由区域归集。记录空时钟开销，不能把两类代理数值直接比较；跨区域代理也不是最终完整策略的无偏预测。
- 每候选建立一个全数据统一配置索引，随机候选次序；同一索引测量两类代理，测完释放。空间预算为 context16/1024 的叶容量估计。两类代理分别选择全局统一配置、区域联合选择、含有序叶的联合选择。
- 独立验证查询 131072 条，5 轮随机策略次序，以批次平均 ns/op 的中位数选择。候选为所有预算可行的统一配置及两类代理的区域策略。验证只能选择本原型的策略，不能选择 ART/LITS 基线。若相同配置向量产生多个名称，复用同一索引与计时，避免把相同算法的分配噪声解释为改进。
- 验证后写出 frozen.json，才生成测试查询。保留“验证最佳统一配置”和“验证最佳策略”两个别名。测试每种数据 262144 条查询，3 个种子、每种 5 轮；不再根据测试结果调整策略。逐条校验在计时外进行，计时内校验汇总值。
- 原生 LITS 固定提交 6f4793dff0dcf66daada49e2f4ae1b1838bfa9cc；ART 为 armon/libart 提交 301046804af165269e37da6725f5a4aec9ecc881，不代表 ART-OLC 或所有 ART 实现。原生源码修改须记录；若正确性门槛失败，保留失败证据并明确排除，不能把自制代理标成 LITS。
- 正式运行前的检查发现 LITS PMSS 的上界插值索引越界（lits_pmss.hpp:1927）；最小补丁把两个上界索引夹至最后一行／列。若该版本进入计时，必须标为 LITS_pmss_patch；原生未修复版本的失败日志保留，不称作原生无修改且内存安全的版本。
- 门槛处理（仍在正式运行之前）：PMSS 修复后，ASan 在 HPT::getCdf 发现 gcpl=0 时读取 key[-1]；补丁按训练阶段相同约定使用起始上下文 0。随后 UBSan 停在内嵌 HOT 的 SingleMaskPartialKeyMapping.hpp:159 未对齐 uint64_t 读取。LITS 因未通过这一门槛排除于本轮正式计时；不关闭 alignment 检查来宣称通过。保留无修改、单补丁、双补丁三次日志。ART 保持原生无修改并进入对照。
- 正式性能对照仅静态精确查找；额外原生适配检查覆盖前缀键、更新、删除和未命中。已有 E3 动态检查不能证明并发、安全回收或在线预算。
- 原型与 sorted_array 报容量估计，不是 RSS。原生基线本轮不提供同口径完整空间计量，记为未知；不作其满足本原型预算的结论。
- 所有 CSV 启用写异常且显式关闭；检查行数、完整末行和字段。保留源代码、版本、原始结果及失败记录。无 PMU 数据，不推断 cache miss 降幅。
