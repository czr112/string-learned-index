# 最终结果表（含每行的版本与来源）

整理日期：2026-09-20。**本表逐行标注"被测版本／对照"与"来源"，因为各项来自不同轮次，不是最终版本的一次统一重测。**

**读法**：`被测版本` 一列写明那一行测的**是哪一个配置**——它**不一定**是最终冻结版本。把 E25 的 `V2` 行（V1＋V2）读成最终版本是错的，因为最终版本还含 C1／C2／S1。

**比值一律来自同一次重复内配对**，按进程取中位数；`(n/N)` 是方向一致的进程数。

## 6. 这张表**不能**怎么用

1. **不能把各行拼成一个"最终版本 vs 原版"的总加速比**——被测版本不同（V2 ≠ C2 ≠ 最终组合），对照也不同（V0／C1／ART／ARR）。
2. **不能把 E25 的 ART 比值改名为最终版本成绩**——E25 的臂不含 C1／C2／S1。
3. **不能跨轮相减或相乘**；每一行的比值都在它自己那一轮、那一次重复内配对得到。
4. **构建三行是历史值**，未随冻结重测。
5. **§5b 的两个候选机制（E31 的 `subblock_reclaim` 与 E34 的 `overflow_stable_store`）都不是冻结版本的成绩**——两者默认关闭，比值是相对冻结版本的，不能并入任何"最终版本 vs 原版"的叙述，也不能与 §1–§5 的行相减或拼接。
