# 下一轮：热组几何描述符（GD）

日期：2026-10-11。状态：计划已固定，未执行入口、未修改索引源码。
承接 [长期路线](STRUCTURE_OPTIMIZATION_ROADMAP_20261011.md) M1；仅做一个结构变量。

## 1. 假说与唯一改动

当前 Region 用三张表保存组几何：`off_`、`bb_`、`sg_`。
`subblocks(g)` 每次由偏移差除以块大小求块数，地址和槽数随后再从这些表取值。
当前写入这些表的地方都在 Region 构造中；Index 的重建/分裂生成新 Region。
假说：构造后连续保存一份查询用描述符，可减少查询时几何推导与分散元数据读取，帮助短键完整点查。
它不包含模型组号或某次查询答案，不缓存 value，也不删除前缀/判重/溢出检查。

首版固定每组 24 B、8 B 对齐：起始偏移 u64、子块数 u32、块大小 u32、槽数 u16、保留填充 6 B。
所有字段均由已完成的真实几何生成。保留原三张表作为同状态对照与现有只读接口的来源；新增副本全额记账。
固定地址模式也按原 `base_of` 的语义生成，不能强行改成 offset-directory 寻址。
计时路径取同一份描述符供 header、entries、suffix、SIMD 有效范围使用；不能仍读旧表而将新副本算作已接入。
不改变模型、CRC、逻辑组数、容量、记录顺序、边界目录、溢出策略或查询 Mode。

## 2. 一次有界入口

普通 bulk_load、`baseline_config(128)+pin_frozen_switches`，C 开、W/S/H 与子块目录关；
Context16/LITS×mixed/skew/tranco 六格，使用 matrix2 原 rows/queries，与 PFX2 入口状态一致。

入口只做以下事项，不做逐查询阶段时钟：

1. 审计几何的全部写入入口与生命周期；核对普通/R1/计划容量/单块与多块寻址的字段范围。
2. 记录各区域/组/块规模、24 B 表的对象、对齐、capacity 与峰值成本；原三表不扣除。
3. 对每组核对块数、偏移、块大小、槽数与原路径；对全部语料键与原查询核对实际地址、候选顺序、found/value。
4. 用同一工具链的无计数优化构建检查实际查询路径：是否仍有整数除法/几何重复推导，以及新路径是否真正使用新描述符。
   反汇编/编译产物只确认代码形态，不换算时间份额，也不认定发生了 cache miss。

入口必须全部成立：六格语义差分零不符；几何消费者/失效规则完整；
新增常驻记账各格 ≤5%；优化构建能确认至少消除一类原几何推导或分散表读取，且未引入每查询建表/间接搜索。
如果编译器已把相关工作全部消除、空间超线或只读语义无法保持，收口，不改描述符宽度挽救。
入口成立只授权一个原型，不声称它是主导段或必有加速。

## 3. 一个隔离原型与正确性

生产源码暂不动；隔离副本实现完整点查，原路径 B0/B1 与 GD 路径 G0/G1 对同一索引状态切换。
描述符准备成本计入完整 bulk_load；计时前允许一次双方相同预热，不把建表藏到预热。

门覆盖：原语料键/查询全量验值、独立有序参考、单/多子块、空/满块、不同槽数与容量、
空键、NUL、0x80/0xff、4096 字节键、碰撞、主块/溢出命中、组/区域边界与未命中。
Context16 覆盖完整二进制键域；LITS 按现行契约测试接受域和明确拒绝，不宣称同域支持。
模拟/实际重建后必须换到新描述符；对旧描述符故意注入的几何错误必须被门拒绝。
ASan/UBSan 先过再计时；保持模型组号、CRC/tag、主块内容与原路径逐项一致。

## 4. 固定 A/B 与停止条件

主指标：**Context16/tranco 原完整查询序列总点查耗时**。
风险格：Context16/mixed、Context16/skew；LITS 三格全部重放，分别报告，不平均进主目标。

5 个串行独立进程×4 平衡重复，固定同一逻辑核；每臂重放原查询 100 遍，无诊断计数/阶段时钟。
比值在同进程同重复内形成。散布底固定为五个进程 B1/B0 配对中位数的 max/min。

接受条件开跑前固定：

- 主目标 G/B ≤0.90，至少 4/5 更快，且 `1/(G/B)` 超过该格散布底。
- 风险格若 G/B >1.05、至少 4/5 变慢且超过散布底，必要条件失败；未分辨明确记未分辨。
- 各格新增常驻 ≤5%，完整构建增量若 >10% 且超过构建 A/A 散布则失败；峰值另列。
- 正确性、查询 checksum、配置同一性与 5×4×4 槽位完整性全部通过。

分析器在正式运行前用固定小记录拒绝缺主指标、缺格、重复键与缺配对；先确认真实运行产出主指标。
一次有效 A/B 不通过即关闭。不增加重复、不换目标、不改 descriptor 宽度或预算线来挽救。
LITS 即使另有收益也作为本轮旁证；主目标失败不临时将 LITS 改成接受目标。
