2026-10-11那版正确性通过，但主块访问区域中位比值为Context16的2.84/3.79/2.05，故停止那版采用。

之后D1–F6A仍使用自研模型，原模型在新结构上的接入被留作待办，没有完成。

   首轮不修改上游算法、不搜索参数；记录编码宽度、段预算、max_error和目标单位。

   训练样本使用实际物理块fence，样本排名直接对应物理块号，避免旧rank→逻辑组→块映射。
   从旧后端沿用固定7符号/8段作为起点，训练参数与适配差分先登记，之后才跑测量。
3. 上游BlockModel保存训练键的string_view前缀；适配层必须稳定拥有训练fence字节，覆盖原输入释放、
