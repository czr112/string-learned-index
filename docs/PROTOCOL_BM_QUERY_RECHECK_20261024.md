# 查询复验登记（2026-10-24）

承接 `eb50b63` 的三处更正，单独修复诊断与计量，不追加尝试 A，不改索引核心或 Context16 默认。本文件先于本轮新计时结果登记。

## 输入与覆盖

- 使用 v3 的 32 条已测轨迹：words / URLs / words_indep 各 8 条，words_100k 8 条。65k/100k 是源键池大小，另报初始与终态活跃键数。
- 热区严格为对应 manifest 的源键池排名闭区间 `hot_range=[lo,hi]`；排名来自完整原始键池，不来自装载后数组的前缀。
- 从完整轨迹重放后的独立 map 生成查询答案。所有 hit 必须在终态存活，所有 miss 必须不在终态；删除键不得进入 hit。每一键同时校验原始排名、热区与期望值。
- 增加一条独立的稀疏写控制轨迹：从 words 95/5 热点增长保留热区内插入，其他操作保留。它用于区分直接写过/未直接写过的初始页范围，不计入原 32 格通过数。
- 输入、源池、终态、查询集、源码闭包和参数均保存 SHA256。原始二进制仍为外部输入，不能宣称远程检出后无需输入即可复现。

## 查询集

所有组按固定种子无放回取样，最多 2,000 个不同键，短组用全体并单列数量；32 格每次进程使用逐字节相同的查询文件。

| 组 | 定义 |
|---|---|
| live_hot | 终态存活，源排名在 manifest 热区 |
| live_nonhot | 终态存活，源排名不在热区 |
| absent_hot | 真实源键，终态缺席，源排名在热区 |
| absent_nonhot | 真实源键，终态缺席，源排名不在热区 |
| synthetic_absent | 原轨迹中出现过的合成缺席查询键，终态确认缺席，不赋予源排名 |
| mixed90 | 无放回混合终态命中与合成缺席，命中 90%、缺席 10%，整数计数明确记录 |

稀疏写控制另测 live_write_touched / live_write_untouched。写影响范围按初始有界页的 2,048 行范围、成功写操作的键定义；它表示“直接写过的初始页范围”，不等同于全局根不变或全部缓存状态不变。必须报告实际写范围数与候选块分裂数。非热区也不等于冷缓存；本轮测预热后的查询。

## 入口、语义与内存布局对照

使用当前两个公共 factory，四个状态同时存活：BM 基线动态、候选动态、同一终态 map 新建的 BM 快照、候选快照。每个进程独立重建；构造顺序随区块轮换。

动态状态完整重放所有操作，对照独立 C++ map 检查返回值与 scan；四状态均全量扫描/回读终态，并逐条核对所有查询答案。Python 另生成终态与查询文件，形成跨语言交叉校验。计时循环无 map、无逐操作时钟、无路径统计；固定集合分批计时并验证答案校验和。

工具先用含空键/NUL/高字节、删除、重复插入、缺失更新与边界排名的夹具自检，并用错误查询标记负对照确认能拒绝错误分组；ASan/UBSan 再检查全部输入的构造、重放与查询校验。语义失败立即停计时，保留失败记录。

## 计时协议（冻结）

- 每格 **16 个独立进程块**，含 100k；每块每状态两次计时作 A/A。
- 每组每状态先做 4 次未计时查询遍历。四状态用 Williams 顺序轮转，每个位置每 16 块出现 4 次；第二遍反向，组顺序随区块轮转。
- 每格先在未计入结果的基线校准中，选择组内遍历次数（2 的幂），使一批至少约 **40ms**；上限 4,096 遍。此后冻结遍历次数，所有状态和 16 块共用，不能看结果再挑次数。
- 固定在同一个可用 CPU（默认可用集合中编号最小者），保存硬件、编译器、亲和性及全部原始样本。保留全部重复，不取最小值，不删慢进程，不追加结果导向重复。
- 校准后实际批长可能因运行条件变化而不同，原样报告。测量不够稳定时允许结论为未定，不通过改门槛或补挑样本通过。

## 分析与判据

每个进程块先对两次测量的 log 耗时取均值，再计算同进程的配对 log 比；只有 16 个进程块是独立样本，组内遍历和两次 A/A 不扩充 n。采用 `t(0.975,n-1)` 构造均值 log 比的 95% 区间，再指数变换。

- 候选动态/BM 动态：区间上界 ≤1.05 为通过，下界 >1.05 为回退，跨门为未定。
- 动态/同 factory 同终态快照：区间上界 ≤1.15 为通过；其他结果分为回退或未定。
- **新增测量质量门**：对参与比较的每个状态，第二次/第一次 A/A 的配对 log 比 95% 区间必须落在 `[1/1.05,1.05]`。不满足则比较记为“测量未定”，同时保留其性能区间，不能判定算法通过或回退。此门与历史门分开记录。
- mixed90 是本轮终态固定查询的主指标；各子集是诊断指标。各区间为点态 95%，不宣称所有组同时具有 95% 覆盖，也不把终态查询替代完整混合轨迹中的 find。
- 原先 32 格混合轨迹 find 另做明确标注的**既有记录重分析**，同样按进程配对、使用 find 自己的 A/A；它不是新增实验，不能与新终态查询混为同一通道。
