## 1. 方向与预算

主线进入 **M4：主块与溢出记录归并时，利用现有有序块的边界，一次证明一段可连续输出**。
目标是 Context16/grow/tranco@200% 的完整物化 scan256，减少 WIDE 写后状态仍存在的扫描成本。
C/W/S 保持已知适用范围；GD、M2、H、Q、PFX2 的既定负结果不重开。
M3 保留为普通构建下显式开启的空间候选，当前不作默认翻转。

本轮顺序：一次短正确性补验 → 一次入口 → 入口通过才做一个归并原型与一次有效 A/B → 必要的集成复测 → M5。
装置缺陷可以修复；负结果不通过改段宽、换主目标、增重复或更换风险格挽救。

## 4. 一次入口：证明可部署的工作减少

首版只批量消费**主块的有序连续段**，溢出游标保留原逐条路径，不引入第二种查找算法或持久边界表。
段定义及探测策略在看新数据前固定：

1. 到达一个新的非空主子块时，令 r 为当前槽位到该块末尾的记录数，并按 scan 剩余返回长度裁剪。
2. 仅当 r≥4 且溢出侧还有记录时，比较该段末键和溢出当前首键。
   末键严格小于对侧首键才可直接逐行产出整段；比较使用运行时现有描述符/后缀，不借参考答案。
3. 证明失败则该子块余下部分走原逐条归并；本子块不重复探测。
   不附加二分寻找短段、不搜索别的段宽。边界相等沿用原有平局规则。
4. 对侧耗尽时原算法本来就无需跨侧比较；这类单侧输出不能充作“新免掉的比较”或有序段入口收益。

按实际 `scan(start, limit)` 取计数增量，保存所有起点，不拿跨维护/校验的累计计数推断扫描工作。
独立诊断影子游标模拟上述可实施策略；原扫描结果、影子序列和有序参考逐行一致。
记录原跨侧比较 C_old、候选逐条比较、成功/失败边界证明比较、比较字节、段长、输出侧切换和全部输出行。
计数的字节含义必须固定，不能将传给 compare 的长度冒充硬件实际访存字节。

**入口条件沿用路线图，100% 和 200% 的 Context16/grow/tranco/scan256 分别判定，均须通过：**

- 至少 50% 的实际输出属于上述有对侧、已证明、实际产出长度 ≥4 的段。
- `1 - C_candidate / C_old ≥ 30%`；C_candidate 包括成功和失败的所有新增边界比较。
  C_old=0 时记入口不成立，不能除零或按 100% 节省处理。
- 答案和原结构状态全等，W 及候选的相关分支真实触发；无隐藏常驻元数据。

比例用原起点队列的行数/比较总量加权，同时交付逐起点分布。
失败边界读取的字节、次数和长键风险另外报告；比较次数减少只授权一个原型预算，不等于时间节省。
任一目标状态不满足即关闭这一个机制，转 M5；不从风险格挑替代主目标。

每个检查点对照独立参考的完整键和值，证明成功批量与失败回退分支都被执行。

以及两后端 same/mixed 的 0%/25%/200% 均保存 scan16/256/4096、命中/缺席点查、构建、维护与空间。

主指标为 **Context16/grow/tranco@200% 的完整 Index::scan256**：
更新后先执行 scan256，原 17 起点连续两遍，包含完整结果物化与释放；首遍也计入主总时长。
随后做其他计时和正确性校验；不能先扫一遍消掉首次代价。此处是新轮次的固定顺序，
不把绝对时长与历史不同顺序的装置直接相减。
首遍、第二遍分别记录。逐调用首批探针可复用已有独立计时装置，报告全样本和最大值，不删慢调用，
不把这点样本包装成可靠 P99。

预注册判定（延续现有五进程口径）：

- 每进程对四重复的 B0/A0 取中位，再取五进程中位 m。
  A/A 底 F 为五进程 A1/A0 中位的 max/min；B1/B0 和 B1/A1 一并报告，不能事后改选收益更大的一对。
- **主目标通过**：m≤0.90、至少 4/5 进程更快，且 1/m>F。
- **必要风险失败**：任一已登记 scan/点查/维护格中位 >1.05、至少 4/5 更慢且超过该格 F。
  构建按路线图采用 >10% 且可分辨的上限；总新增常驻不得超过 5%。首版不新增持久目录，
  该项预期为 0；开关及 `sizeof` 的对象增量仍须实测、计入，不能预填总空间增量为 0。
- 首遍总时长和独立首批探针的逐进程最大值也受同一 >5% 可分辨风险条件约束；
  不能用第二遍收益抵消新增首批停顿。未分辨需列在采用风险中。
- 分别报告完整耗时与 consume 机制结果；主指标未通过，即使比较少了或 consume 更快也关闭。

运行前小样本自检：缺主指标、缺预定重复/进程/格子、配对重复、配置差异越界、checksum/操作数不符均必须拒绝。
分析器验证预定全集，不能仅对“已出现的格子”算出一个好看的汇总。
不因统计未分辨追加进程或重选查询；它是本轮的有效结局之一。
