# S3：只读接口与宽证书回退

基点 ca11873。前轮原型及原始结果冻结，不改变生产 Index、默认后端或 LITS。

1. 独立 StaticPhysicalIndex 类型脱离动态 Index 和模型依赖，保持 2048 键区域、16 条物理块、7×9-bit 坐标、3 块正常证书上限。
2. 接入正式 v1 工厂，一次 bulk_load，自持有全部键值，原生 find/owning scan；写操作和 range_sum 明确 unsupported。
   按契约修正共用验收中“可选操作必须支持”的假设，既有动态臂也通过同一程序重新检查。
3. 验证全量命中/未命中、预测窗口、扫描与独立有序参考；含空集、空键、NUL、高位字节、4096 长键、碰撞族、块/区域边界、输入释放和结果跨析构。
   失败构建不发布状态，重复成功构建拒绝。ASan/UBSan 通过后才计时。
4. 唯一新候选：实际证书宽度 >3 时，仅在证书范围内对完整后缀 fence 二分，再验证一个物理块。
   不增加目录副本、不改变预测器、不根据语料名称选择实现、不搜索阈值。learned 仍为只读适配器默认；新候选显式 lookup=wide_directory。
5. 六臂：旧原型、新正式 learned、同一 learned 实例 A/A、wide_directory、ART、HOT；同一虚接口。
   5 进程×6 次偶数 Williams 顺序（0/1/5/2/4/3 的六个平移），位置与有向前驱平衡，每臂即时等量预热。
   新种子 2026101202、90% 命中均匀队列，10k 与100k 分列；tranco 再检查均匀抽取并排序的64k规模。
   10k队列20遍、100k队列2遍，均为200k次完整点查；大队列不是冷读结论。真实冷读及更大数据规模留后续独立阶段。
6. 同重复配对后先取每进程中位，再取5进程中位；F=max(max(A/A,1/(A/A))) 为观测带，不是置信区间。
   集成/原型回归 >5%、至少4/5同向且超过 F 则停止采用；skew 新候选/learned ≤0.90、至少4/5更快且收益超过 F 才保留。
   tranco/mixed 回归 >5%、至少4/5同向且超过 F 则禁止通用采用。所有结果都报告实际完整查询耗时，不以计数代替性能。
7. 本次完成接口、门、有限配对结果及判定，同步报告/状态及远程。生产默认和动态维护不在本轮变更范围内。
