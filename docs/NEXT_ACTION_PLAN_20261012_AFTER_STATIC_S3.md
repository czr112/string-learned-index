# S3 后：先消除集成回归，再降低固定导航成本

起点：S3 最终 c 轮。只读类型、接口与正确性完成；整包性能采用未通过。
不改生产默认，不做 LITS 定向优化，不再重跑 S3 来争取通过；已关闭候选保持关闭。

## 1. 当前证据和优先级

- 正式 learned 接口在 skew/100k 比旧原型慢 7.75%，4/5 同向，超过 F=1.0479；这是下一步首先需要解释的回归。
- 宽证书回退在 skew 两队列分别减少 15.6%/14.1% 查询耗时，均5/5更快且通过原门；mixed 没有净收益。
- 100k 查询的回退实验相对 ART：tranco 0.938、mixed 1.066、skew 0.810。
  但10k队列为1.145/1.232/1.021，64k的tranco为1.385/1.368，不能宣布通用追平ART。
- 新结构与旧原型布局空间相同，整包回归尚未归因。不能直接断言一次空指针检查导致了全部损失。

## 2. P0：集成成本归因，先诊断后修改

范围限于我方只读实现、正式适配器与旧原型对照；外部基线不修改。

1. 审核 -O3 下真实 find 路径：包装解引用/状态检查、是否产生额外调用、CRC循环、预测/窗口纠正和标签验证。
   核对完整工作量，而非把源码行数、访问块数直接转换成纳秒结论。
2. 必要时使用一次有界2×2诊断：旧核心/新核心 × 旧堆包装/正式包装，均真实调用 find。
   核心均拥有输入，禁止预知区域号、跳过剩余CRC或只返回预测位置。保留同实例A/A。
   首先看 skew/100k 主格；tranco/mixed只作改动风险检查，不重新铺整个历史矩阵。
3. 只有发现可重复的额外工作，才实现一个最小改动；构建前调用仍须拒绝，生命周期和输入所有权仍须正确。
   不用删除状态检查、改变块尺寸、调阈值或追加重复次数掩盖回归。
4. 完整查询同重复配对，集成/原型 ≤1.05 且无 ≥4/5、超A/A带的回归才通过。
   若归因未成立：记录为未解释的集成回归，继续保留实验接口，停止采用；不凭推测改热路径。

## 3. P1：固定导航成本的结构入口

P0通过后再开。主目标是64k tranco和10k查询下的短键差距，full tranco和mixed/skew为风险格。

1. 统计一次查询必须经历的区域导航、段搜索、证书纠正、CRC字节与精确比较；计数版不用于性能排名。
2. 决定是否值得让外层导航直接给出物理块范围，从而合并现有的区域导航与块预测。
   这是条件候选：必须证明能实质减少依赖步骤，同时保守覆盖缺席、前缀键和坐标碰撞。
3. 不先实现多个路由器，不搜索坐标/摘要宽度；入口不成立就关闭这一方向。
4. 若进入原型：保持完整find及自持有scan，通过独立有序参考与ASan/UBSan；单一差分与同布局控制配对。
   目标主格完整耗时至少下降10%、≥4/5一致且超A/A观测带；其他格超过5%的清晰回归阻止通用采用。

## 4. 之后的阶段

- 只读性能门通过后，补一次明确的首次遍读/缓存驱逐状态检查及不同缺席键形态；有界验证，不扩建论文级协议作为新主线。
- 静态路线收口后，另设计局部写余量、分裂和模型重建；同时计常驻、峰值与维护暂停。
  保留动态 Context16 对照，不把静态收益直接写成可更新索引的收益。
- 后续每轮均交付简表、原始配对记录、关闭/保留判定和唯一仓库同步。
