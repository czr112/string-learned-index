# 下一步决策：WIDE × 紧凑区域导航的有限组合轮

日期：2026-10-10。性质：行动计划，尚未执行本轮实验。
本文件替代 `NEXT_ACTION_PLAN_20261009.md` 的后续顺序。

## 1. 决策与依据

下一步只回答一个新问题：**扩大子块回收与紧凑区域导航，在同一索引状态上能否同时保留收益？**
选定 `WIDE`（`subblock_reclaim=true`、`reclaim_widest=true`）与
`compact_region_routing` 两个因素；全部保持非默认。

- 低活跃回收、C-2、E3 三轮入口已收口，不再重复。
- G3/G5 已验证 WIDE；G5 还证明其收益强烈依赖模型映射：Context16 的收益不能搬给 LITS。
  本轮新增价值是与导航候选的交互，不能把重跑 WIDE 写成新结构贡献。
- 紧凑导航补测已完成，tranco 的命中查询四格方向均为 5/5，其中两格依项目现有噪声规则仍未分辨。
  使用 `RESULTS_COMPACT_ROUTING.md` §7，不能只引用早期全未命中轮的 22%/26%。
- 不将 O1 加入本轮。E34 的原始 O1 有读/扫描代价；当前实现还有 E36 的 O8/T8 区别，
  T8 在 skew 上点查仍为 B 的 1.181–1.266 倍。E3 的搬移字节量不能替代可节省时间，
  也未证明 WIDE 之后残余容器仍值得换表示。O1 保留既有场景候选身份，不由这次诊断升格。
- 空块字节拒绝是块级事件，不能直接当作可挽救插入数。将空块作为一等候选属于另一项改动，
  本轮不据此扩展低活跃回收。

证据：`RESULTS_G3_WIDEST.md`、`RESULTS_G5_X2BACKEND.md`、`RESULTS_E36.md`、
`RESULTS_A3_ENTRY.md`、`RESULTS_LOW_ACTIVITY_ENTRY.md`、`RESULTS_E3_ENTRY.md`。
以上路径均相对 `02_Code_and_Experiments/validation_e25_20260918/`。

## 2. 固定对照

每个后端分别运行四臂，后端之间不计算候选收益比值。

| 臂 | subblock_reclaim | reclaim_widest | compact_region_routing |
|---|---:|---:|---:|
| B：当前发布配置 | 0 | 0 | 0 |
| W：扩大回收方案 | 1 | 1 | 0 |
| C：紧凑导航 | 0 | 0 | 1 |
| WC：组合 | 1 | 1 | 1 |

共同固定：发布开关（含 `compact_plan_commit`）、模型、Mode、初始容量计划、逻辑映射、
主块预算、回收预算及阈值。`overflow_stable_store`、`overflow_inline_tag`、
`overflow_migrate`、`reclaim_low_activity` 均为 false。
W 是已验收的双开关方案，本轮不重新拆 E31 与 widening 的贡献。
断言 B/C、W/WC 只差导航；B/W、C/WC 只差 WIDE 的两个必要开关。

直接报告同重复内的 W/B、C/B、WC/W、WC/C、WC/B；不乘历史比值预测组合收益。
WC/W 回答在回收后的状态里导航是否仍有价值，WC/C 回答启用导航后回收是否仍有价值。

## 3. 执行顺序

1. **扩展现有基准，先不改索引实现。** 复用 `bench_routing.cpp` 的两阶段查询与参考表验收，
   复用 WIDE 的容量计划及替换序列；加入四臂与同轮扫描。新目标、新输出名，保留历史装置和结果。
2. **四臂正确性门及 ASan/UBSan。** 逐条对照独立参考表的命中、值、规模、全量内容与扫描键序；
   覆盖删除重插、重复键、区域分裂、导航失效及摘要碰撞。诊断构建证明 widening、摘要搜索、
   结构版本变动后的目录重建实际执行；未执行单列 NOT EXERCISED，不算机制验收通过。
   诊断计数构建与干净计时构建分开。
3. **同轮计时。** mixed/skew/tranco × Context16/LITS × same/grow；
   静态态与 25/50/100/200% 替换检查点。从各检查点的存活键及参考表生成固定查询，
   计时外逐条验答案，记录期望/实际命中数；命中与未命中分别报耗时。
   扫描使用同一批起点及固定三档长度（16/256/4096），逐行验内容。
   扩容和结构变动后的首次导航目录重建必须计入构建或维护，不能被预热隐藏。
4. **复用现有调度。** 每个后端四臂，5 独立进程 × 4 重复，位置轮转，同重复内配对。
   不增加 ART/HOT 臂，不扩建计时协议，不做参数搜索。
5. **收口。** 每格同表列构建、完整维护、点查、扫描、总空间、主块字节、溢出记录/字节、
   导航元数据和分支执行状态。报告配对范围、方向计数及现有噪声指标，未分辨不等于等效。

纯插入仅作为正确性与分裂/目录重建覆盖；本轮主性能主张限于静态及长期替换，
不把替换收益推成纯插入收益。若要提出纯插入性能主张，另行同轮测量。

## 4. 停止与采用

- 正确性、固定预算或身份核验失败：停止计时，先修装置或实现，再按新身份复跑。
- WC 相对 W/C 没有可分辨的增量收益：保留各自已验证场景，不为组合添加补丁或改阈值。
- WC 有维护或点查收益，但点查/扫描出现可分辨回归：登记取舍，保留场景候选，不能升为通用默认。
- WC 同轮保留可分辨收益、正确性与空间验收通过、未观察到读/扫描回归：成为完成的组合候选。
  未观察到回归仍不等于证明性能等效；本轮不自动改默认。
- 完成组合判断后，只对保留下来的配置做必要的外部复测。
  静态四方点查只能评价导航及组合的静态部分，不能证明 WIDE 的长期更新收益。

若组合收益不足，下一项应从所选后端和索引状态的**残余主块检索/放置成本**选取一个候选，
现有 E3 分解尚不足以决定具体改法；届时做一次有界入口诊断，避免重开泛化的分配优化。
