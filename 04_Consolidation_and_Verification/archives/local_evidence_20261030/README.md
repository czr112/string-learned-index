# 本地历史文本证据归档

本轮整理的是本机已有文件，未重跑历史实验。`catalog.json` 逐项记录原相对路径、字节数、SHA-256 和处理方式。

1,520 份文本证据及冻结源码合计 20,319,876 B，保存为 3,340,887 B 的 `historical_text_records.tar.gz`；归档内成员逐项 SHA 已流式复核。9 份嵌套 gzip 也先解压核对为 UTF-8 文本，未发现所扫描的私钥/GitHub/AWS/API token 特征。此扫描不是完整安全证明。

两个 extensionless ELF、六个 `.DS_Store`、三个冻结 `.gitignore` 及一份 30,338,576 B 的编译日志没有纳入归档；完整 SHA 和原因仍在 catalog。大日志继续留在原工作区，未删除。两个补齐导航闭包的 Markdown 文档分别按原路径提交；根目录空 `=` 探针保留在原处。

归档不含构建二进制、原始键语料或派生 `.bin`。不得把归档动作说成历史实验在新版本上复验通过。旧报告的输入/源码/性能身份不变。

复核时先检查归档 SHA，再遍历 tar 的普通文件成员，对照 catalog 中 `archived_text_evidence` 的路径、长度和 SHA。若需解包，使用一个全新目录，避免覆盖工作树中的同名历史证据。
